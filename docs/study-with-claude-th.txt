---------------------------------------------------------------------
วิธีที่ 1 (แนะนำ)  ให้ Claude อ่านจาก GitHub โดยตรง ไม่ต้องโหลดไฟล์
---------------------------------------------------------------------

ตั้งค่าครั้งเดียว 5 นาที
  1. ต้องมีบัญชี GitHub ฟรี (สมัครที่ github.com ถ้ายังไม่มี)
  2. เปิด claude.ai -> Projects -> Create project ตั้งชื่อเช่น "Surgery"
     (ถ้าในแอปบน iPad/มือถือไม่มีเมนูข้อ 3 ให้เปิด claude.ai ใน Safari/Chrome แทน)
  3. ในโปรเจกต์ กด + -> Add from GitHub แล้ว login GitHub (ครั้งแรกครั้งเดียว)
  4. วางลิงก์ https://github.com/playerplayrh/surgery-year-4 แล้วติ๊กทั้ง repo
     ถ้าขึ้นว่าใหญ่เกิน ให้เอาโฟลเดอร์ images/ และ Survival Guide/ ออก
  5. เสร็จ ถามอะไรก็ได้ในโปรเจกต์นี้ Claude จะค้นจากเนื้อหาใน repo เอง

อัปเดตของใหม่
  เวลามีเพื่อนเพิ่มเนื้อหา กดปุ่ม sync (ลูกศรหมุน) ข้างชื่อ repo ในโปรเจกต์
  ไม่ต้องตั้งค่าใหม่ ถ้าไม่กด Claude จะตอบจากฉบับเก่า

ข้อดี: ไม่ต้องโหลดอะไร ได้ของล่าสุดแค่กด sync และแก้ repo ไม่ได้ (ลบของใครไม่ได้)


---------------------------------------------------------------------
วิธีที่ 2 (สำรอง)  โหลดทั้ง repo เป็นไฟล์เดียว แล้ว upload เข้า Project
---------------------------------------------------------------------

ใช้เมื่อไม่มีบัญชี GitHub หรือวิธีที่ 1 ใช้ไม่ได้ (ไม่ต้อง login อะไรเลย)
  1. เปิด https://github.com/playerplayrh/surgery-year-4
  2. กดปุ่มสีเขียว Code -> Download ZIP  (ได้ทั้ง repo เป็นไฟล์เดียว)
  3. แตก zip แล้วลากไฟล์ .md ของเรื่องที่ต้องการเข้า Project บน claude.ai
     (Add content -> Upload) เช่น ทั้งโฟลเดอร์ textbook/chula-black-1 หรือ facts
  ข้อเสีย: ไม่อัปเดตเอง ถ้ามีของใหม่ต้องโหลดซ้ำ

แค่อยากเปิดอ่านเฉยๆ: เปิดลิงก์ repo แล้วกดเข้าโฟลเดอร์ได้เลย GitHub แสดงไฟล์ .md ให้อ่านสวยๆ

---------------------------------------------------------------------
อยากเพิ่มเนื้อหาของตัวเอง
---------------------------------------------------------------------

repo นี้ใครก็อ่านได้ทั่วโลก ข้อมูลคนไข้ต้องไม่หลุดเข้ามาเด็ดขาด

ทางง่าย (ไม่ต้องใช้ GitHub)
  1. ลบข้อมูลคนไข้ก่อน: ชื่อ, HN/AN, วันเกิด, วันที่, เตียง, เบอร์โทร, รูปที่เห็นหน้า/ป้ายชื่อ
     (ชื่ออาจารย์และ resident ใส่ได้)
  2. ขอเจ้าของ repo ให้แชร์โฟลเดอร์ Google Drive "Surgery Group" ให้
  3. upload เข้าโฟลเดอร์ Surgery Group/inbox/  ตั้งชื่อไฟล์ว่า  หัวข้อ - ชื่อเรา
  4. เจ้าของ repo จะนำเข้าให้ ไฟล์ย้ายไป done/ = เข้าแล้ว, needs-fix/ = มีอะไรต้องแก้

ทางสำหรับคนที่ใช้ Claude Code บนคอม
  อ่าน docs/collaborator-guide-th.txt ใน repo
